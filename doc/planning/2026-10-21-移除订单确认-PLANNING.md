# 移除订单确认 Planning

## 实施计划

1. 移除订单模型中的 `confirmedAt`、`confirm` 批量操作、`unconfirmed` 进度值及相关辅助函数，并兼容清理历史字段。
2. 移除服务端确认校验、确认操作、确认列读写和未确认查询条件；批量 API 不再接受 `confirm`。
3. 移除订单页确认按钮、状态、回调、通知与“未确认”进度选项，并清理编辑、结账、赛果处理中的确认字段联动。
4. 更新订单服务测试，删除确认能力与未确认筛选用例，增加旧确认字段被忽略以及筛选值被拒绝的回归覆盖。
5. 运行相关测试、全量测试、Lint、构建，并用浏览器验证桌面端和移动端订单操作区与进度筛选。

## 接口与数据兼容

- `/api/orders/bulk` 删除 `confirm` 操作；旧请求返回“批量订单操作类型无效”。
- `/api/orders?progress=unconfirmed` 不再识别该值，按未指定进度处理。
- 不新增或修改 D1 迁移；保留已发布的 `confirmed_at` 列和索引，应用不再依赖它们。
- 历史 `confirmedAt` 不再进入应用模型或新写入的 `data_json`，其它订单字段和账本口径保持不变。

## 发布影响

- 属于删除功能与行为调整，按 minor 版本发布为 v1.38.0，并在发布提交中同步更新 `UPDATE.md`、`package.json` 和 `package-lock.json`。
- 发布目标为 `origin/main`、Cloudflare Worker `smgr-cloud` 和正式域名 `smgr.online`。本次没有数据库结构变化，跳过远端 D1 迁移和生产订单重写。
