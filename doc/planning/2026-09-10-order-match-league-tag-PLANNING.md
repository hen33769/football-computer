# 订单比赛联赛标签 Planning

日期：2026-09-10

关联 Research：`doc/planning/2026-09-10-order-match-league-tag-RESEARCH.md`

## 目标

- 在订单页每场比赛的主客队名称后显示对应联赛 Tag。
- 复用现有联赛颜色设置与可读文字颜色逻辑。
- 保持订单数据、筛选、赛果和桌面/移动端布局兼容。

## 实施方案

1. 在订单比赛队伍名称节点末尾按 `match.league` 条件渲染 Ant Design `Tag`。
2. 使用 `getLeagueTagColor(appSettings, match.league)` 读取默认或自定义颜色，并用 `readableTagTextColor` 设置实心标签文字颜色。
3. 增加订单专用标签类，控制左侧间距、字号、行高与垂直对齐。
4. 运行 diff 检查、完整测试、Lint 和构建，并用桌面与移动视口验证订单卡片。

## 接口、数据与兼容

- 不修改接口、订单模型、D1 或持久化数据，不需要数据库迁移。
- 历史订单直接使用其已有的 `match.league`；空值不渲染标签。
- 标签为只读展示，不改变联赛颜色编辑入口。
- 本次不提交、不推送、不部署，因此不调整版本号或 `UPDATE.md`。
