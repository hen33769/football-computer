# 队伍名称归组与别名 Planning

日期：2026-09-01

关联 Research：`doc/planning/2026-08-31-team-aliases-RESEARCH.md`

## 已确认需求

- 不设置固定主名；同一队伍由一个稳定组 ID 关联多个名称。
- 每个队伍可保存多个名称，但同时只能激活两个名称，并按 `activeSlot = 1 | 2` 保留顺序。
- 比赛接口返回的名称可以是两个激活名称之一，也可以是该队伍的其他已保存名称。
- 接口名称是激活名称 1 时显示 `(激活名称2)接口名称`；接口名称是激活名称 2 时显示 `激活名称1(接口名称)`；接口名称是非激活名称时显示 `(激活名称1)接口名称`。
- 正式版未登录用户、登录用户和 GitHub Pages 游客 Demo 都要显示公共别名。
- 别名不纳入现有个人 JSON 导入/导出和完整数据备份。
- 普通用户只读，管理员可以新增、修改、删除名称并切换激活名称。

## 目标

- 建立全局共享的队伍名称归组数据。
- 公开接口一次返回所有配置，投注页用内存索引按接口队名 O(1) 找到队伍组，不逐场请求。
- 通过数据库唯一约束和服务端校验确保一个规范化名称只能对应一个队伍组。
- 不改变 `MatchItem.home/away`、订单快照或比赛缓存中的原始名称。

## 数据结构

新增两张表：

### `shared_team_name_groups`

- `id`：UUID，队伍组稳定身份。
- `updated_by`：最后修改管理员，可为空。
- `updated_at`：最后修改时间。

### `shared_team_names`

- `id`：UUID，名称记录稳定身份。
- `group_id`：关联队伍组，级联删除。
- `name`：原始展示文本。
- `name_key`：NFKC、trim、合并空白、中文 locale 小写后的匹配键，全局唯一。
- `active_slot`：`NULL`、`1` 或 `2`；同一个组每个槽位最多一条记录。
- `updated_by`、`updated_at`：修改审计字段。

数据库层保证名称不重复；服务层另外拒绝空名称、规范化后相同的名称、主副激活槽位不足/重复以及跨组名称冲突。新增或修改组时使用事务，避免切换激活槽位时产生半完成状态。

## 接口与前端数据流

- `GET /api/team-aliases`：无需登录，返回完整名称组及两个激活名称。所有名称（包括未激活名称）都返回，用于识别接口名称；只有激活名称用于展示。
- `POST /api/team-aliases`：管理员新建队伍组，至少包含两个名称并指定两个激活槽位。
- `PATCH /api/team-aliases/[groupId]`：管理员修改组内名称或激活槽位，带版本/更新时间校验。
- `DELETE /api/team-aliases/[groupId]`：管理员删除整组及其名称。

`FootballRoute.bootstrap` 与公共比赛请求并行读取别名。正式版使用同源接口；standalone 使用 `https://smgr.online/api/team-aliases`，Worker 对公开 GET 增加允许 GitHub Pages 来源的 CORS 响应。写接口仍只接受同源账号会话，不开放跨域写入。

前端将返回值转换为：

```ts
Map<string, {
  groupId: string;
  activeNames: [{ name: string; nameKey: string }, { name: string; nameKey: string }];
}>
```

Map 中每个已保存名称都指向同一组。渲染时按当前接口名称和 `activeNames` 的槽位决定正常文本与灰色小号括号文本。

## 兼容策略

- `MatchItem`、订单数据、比赛 D1 快照和现有 JSON 格式不增加别名字段。
- 订单页、订单详情和历史快照继续显示保存时的原始队名，不因公共配置变化而重写历史数据。
- 没有别名接口、别名接口暂时不可用或队伍未配置两个激活名称时，保留原始接口队名，不阻塞投注页。
- GitHub Pages 游客版无法使用相对 `/api`；通过公开正式版 URL 读取，失败时静默回退为原始名称。
- 现有设置 JSON 导入/导出保持只处理联赛颜色等个人设置，不携带公共别名。
- 不修改当前工作区已有订单已支付筛选和收入统计改动；所有修改避开其业务逻辑和测试断言。

## 验证重点

- 相同 `nameKey` 在同组或跨组新增/修改时均被拒绝；并发写入依靠数据库唯一约束返回 409。
- 一组有 3 个以上名称时，最多只有槽位 1、2 两个激活名称；切换槽位后旧激活状态被清除。
- 接口名称分别为激活名称 1、激活名称 2、未激活名称和未配置名称时，展示文本和灰色括号方向正确。
- 匿名云端用户可以读取并显示别名；普通账号不能写入；管理员可以新增、编辑、切换、删除。
- 云端投注页和 GitHub Pages 游客版均能读取同一份配置；没有别名接口时比赛仍可正常显示。
- 桌面端与 390px 移动端设置卡片和比赛卡片无横向溢出，控制台无 warning/error。
