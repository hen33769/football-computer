# 订单联赛命中率柱状图 Planning

日期：2026-09-10

关联 Research：`doc/planning/2026-09-10-order-league-accuracy-chart-RESEARCH.md`

## 目标

- 在订单筛选卡“比赛类型”标题旁增加联赛命中率入口和两行汇总。
- 基于 `filteredSavedSlips` 按联赛汇总命中、未命中、未确认和命中率，并用 ECharts 柱状图展示。
- 支持联赛多选、“不统计比分”、“重复计数”和“固定 Max”，保持桌面端与移动端可用。

## 实施方案

1. 新增联赛正确率纯函数，按“订单 × 比赛 × 已选玩法”分类，兼容 `hits`、`resultValues`、`failedMatches` 和旧订单不完整结果。
2. 默认重复统计每个订单中的预测；关闭“重复计数”后按“标准化比赛 ID + 玩法 + 已选项 ID 集合”去重，并在重复记录间优先采用证据更明确的状态。
3. 正确率使用 `命中 / (命中 + 未命中)`；未确认不进入分母，没有已确认结果时返回 `null` 并显示“—”。
4. 新增联赛正确率弹窗，联赛默认全选、支持清空；“不统计比分”和“重复计数”默认开启，“固定 Max”默认关闭。
5. 使用柱状图展示正确率，柱顶显示百分比，tooltip 展示命中、未命中、未确认；y 轴最小值固定 0%，固定 Max 开启时最大值为 100%，关闭时使用当前数据最大值（全为 0% 时以 1% 避免零区间）。
6. 在“比赛类型”标题旁加入 `BarChartOutlined` 入口，传入 `filteredSavedSlips`，不受订单列表分批渲染数量影响。
7. 增加聚合纯函数测试，并完成完整测试、Lint、构建及桌面/移动浏览器验证。

## 接口、数据与兼容

- 不新增 API，不修改订单模型、云端接口或 D1；账号版仍只统计当前查询已加载的最多 500 条候选订单经过全部前端筛选后的结果。
- 开关和联赛选择只存在于弹窗本地状态，不持久化到账户设置或浏览器存储。
- 空联赛不生成柱；同场其他玩法在“不统计比分”开启时仍正常统计。
- 去重冲突时状态证据优先级为命中、未命中、未确认；具体命中值比整场失败标记更可信。
- 发布按新增功能使用 minor 版本 `v1.25.0`，同步更新 `package.json`、`package-lock.json` 与 `UPDATE.md`；无数据库迁移或生产数据重写。

## 实施结果

- 新增 `app/league-accuracy.ts`，统一处理玩法级状态分类、正确率计算、比分排除与重复预测去重。
- 新增 `app/LeagueAccuracyModal.tsx`，提供联赛多选、三个统计开关、柱顶百分比、统计 tooltip 与异常重试，图表不提供缩放功能。
- 在订单页“比赛类型”标题旁增加图表入口，并将完整的 `filteredSavedSlips` 传给弹窗。
- 图表入口首行展示整体命中率，副行展示当前筛选结果中的成功订单数量；命中率汇总与弹窗统计开关共享状态。
- 每根柱顶首行展示命中率，副行展示该联赛 `命中 + 未命中` 的已确认场次。
- 每根柱通过 `getLeagueTagColor` 复用设置页的联赛标签颜色，颜色设置变化后同步更新图表。
- 新增响应式样式和 7 项聚合测试；无联赛、联赛选择清空及无已确认结果均有明确展示。
